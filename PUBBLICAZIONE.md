# Pubblicazione della guida Lungomare 70

La guida contiene 12 sezioni, 7 lingue e 10 fotografie della struttura.
Lingue: italiano, inglese, tedesco, francese, spagnolo, olandese e polacco.

## File del sito
- index.html
- style.css
- app.js
- content.js
- .nojekyll

Le immagini sono incorporate nei file HTML e JavaScript: non serve una cartella di fotografie esterna. Non sono richiesti installazione di dipendenze o compilazione. Il README.md originale è conservato.

## Pubblicazione tramite GitHub Pages
Nel repository AlbyIt/Lungomare70:
1. Aprire Settings > Pages.
2. In Build and deployment selezionare Source: Deploy from a branch.
3. Scegliere il branch main e la cartella / (root).
4. Premere Save soltanto quando si desidera pubblicare.
5. Attendere il completamento della pubblicazione e usare l'indirizzo mostrato da GitHub Pages.

La pubblicazione non è stata attivata durante la preparazione della guida.
